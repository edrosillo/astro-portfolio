Which interactive features would you want?

These are the "wow factor" elements that make visitors remember your site. Select all that excite you.

A

Custom Cursor

Replace the default cursor with a small crosshair, dot, or glitch-trail cursor that changes state on hover (e.g., expands over clickable elements). Subtle but immediately signals "this person builds custom experiences."

B

Smooth Page Transitions

Instead of hard page loads, sections/pages transition with a brief glitch-flash or VHS-tracking wipe effect. Makes the site feel like a single cohesive experience rather than separate pages.

C

Scroll-Triggered Animations

Elements fade/slide in as you scroll. Section numbers count up. Skill bars fill on reveal. Project cards stagger in. Keeps the page feeling alive as you explore.

D

Easter Eggs / Konami Code

Hidden interactions — a Konami code that triggers a full-screen glitch meltdown, clicking a hidden element that reveals a retro mini-game or secret message. Memorable and shareable.

E

Sound Design (Optional Toggle)

Subtle UI sounds — a soft click on navigation, a glitch buzz on hover, a boot-up chime on load. Off by default with a toggle to enable. Risky but unforgettable when done right.

Select as many as you want — we'll prioritize during design.
